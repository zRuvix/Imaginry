# Lab

The Lab is a second room that opens on whatever design is already in the studio. The studio stays free. The Lab is the paid session: one look goes in, a set of directions, a reaction, and a take come out.

The studio is one canvas, one clock, and the R key, which replaces the design. The Lab never does that. It keeps the original and works on copies.

People pay for the hour this replaces. A client asks for a few directions, a hover, a texture, and a file of the one they picked. Today that is duplicate, nudge, export, repeat. One panel on its own is a toy. The six together are a session, which is the thing worth a subscription.

## 1. Board

The stage, same role as the canvas.

- A live grid of 4, 9, or 16 cells, all playing the current stack.
- Lock any layer. Grain, glass, and the gradient can sit still while everything else moves.
- Star cells. Compare two, full size, side by side.
- Pull a cell back into the studio as its own design. The one you started from stays.
- A run history, so the last few grids are still there after you change a slider.

## 2. Mutate

The generators, same role as the effect list. Each one fills the board.

- **Seed.** Same layers, new noise.
- **Palette.** The colors already in the design, walked into rotations, complements, and splits.
- **Range.** Pick one slider. The cells step across it.
- **Swap.** Same stack, a different finish on top: halftone, dither, ascii, grain.
- **Breed.** Two starred cells. The next grid is their children.
- **Distance.** A single amount for how far a cell may drift from the original.

## 3. Drive

Inputs. The studio only has a clock and a speed multiplier.

- Pointer position, speed, and click.
- Scroll, previewed in the Lab so you can feel a page moving over the look.
- A track or the mic, split into low, mid, and high.
- Tap tempo, so the loop locks to a beat instead of a free clock.
- A map: this signal drives this slider, by this amount, with smoothing. Any control in the stack can be a target.

## 4. Field

A simulation layer the 51 effects are not. Sparkle, bokeh, and blobs stay in the studio. This sits under or over the stack.

- A particle field: count, size, drag, lifespan.
- A flow field the particles read, so they drift instead of jitter.
- Trails and ribbons.
- The pointer as an attractor or a repeller.
- Audio into spawn rate and turbulence.

## 5. Matter

Still plates from the same look. This is the texture-lab job: a file you can drop into a comp.

- A tileable version of the current design, with a 2×2 and 3×3 repeat so you can see the seam.
- Isolated plates: color only, grain only, height from the luminance.
- Large stills of those plates, bigger than a hero export, for print and mockup.

## 6. Take

How the session leaves. The studio already exports one still and one seamless loop.

- Record the play. Pointer and audio are in the file, not only the looping clock.
- A contact sheet of the starred cells, one image.
- A still and a loop for each star, named as a set.
- A review link to the board. Someone else stars a cell. You pull that one into the studio.
